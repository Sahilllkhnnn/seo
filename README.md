# Élané Atelier — Luxury Fashion Storefront

A professional luxury e-commerce front-end for a ladies fashion brand in India.
Built with **React + Vite**, **Tailwind CSS**, **Framer Motion**, and **@react-three/fiber** for 3D interactions.

## Features
- Multi-page experience (Home, Shop, Product Detail, Cart, Checkout, About, Contact, Auth)
- Luxury hero with 3D animated sculptural form
- Smooth motion-driven transitions and glassmorphism panels
- Responsive layouts for mobile, tablet, and desktop
- Animated cart drawer, product filters, and 3D product preview
- Dummy product catalog stored as JSON for easy customization

## Getting Started
```bash
npm install
npm run dev
```

## Customization
- Update brand styles in `tailwind.config.js`
- Swap imagery and product data in `data/products.json`
- Edit sections in `pages/` to adjust layout or content
